Every button & box

Find a movie box

Type a movie title to search the selected source, paste any movie/trailer page URL, or paste a direct MP4/M3U8 link.

Search source

Auto tries Archive.org first (free, no account), then the ww8.123moviesfree search API, 123movieszfree and IMDb. You can force one site here.

Open / Search

Runs the search, opens the pasted page, or plays a pasted direct video link. Enter does the same thing.

Result cards

Pick a movie. The reader loads its info page and finds trailer/video sources.

Video only

Plays the first detected MP4/M3U8 file inside the reader stage, with the source site's page removed. It tries the direct media URL first and then a Google Translate media route. Archive.org movies and signed 123Movies players are handled by the in-reader Movie player source.

Info text

Shows only the extracted title, synopsis, year, genre and cast in the reader stage. The cover is loaded through the Google image proxy.

Refresh sources

Re-reads the current page and rebuilds the source list.

Clear

Stops playback and hides the stage.

Movie player (in reader)

Builds the signed 123Movies/ployan player link and runs it inside the reader stage. No account, no new tab. Use this when the site only exposes a player page instead of a direct video file.

Movie player (Google tab)

Fallback that opens the signed player through Google Translate in a new tab, in case the in-reader player is blocked on your network.

Source buttons

Detected MP4/M3U8 files play in the reader stage using the best working media route. The signed 123Movies player also plays in the stage; other player pages open in a Google proxy tab.

Page view mode

Google proxy tab opens ordinary player/info pages through Google Translate in a new tab. Stage is for direct video clips and the signed 123Movies player — Google-translated pages cannot be framed, so they open in a tab instead.

Google Translate backup

Player pages always use Google Translate. This checkbox only controls the reader-route fallback used for lookup when the direct reader fails.

Menu tab

Opens and closes this control panel.

Help button

Opens this dialog. Press ? anywhere to open it.

HUD

Shows the current title and source name over the player.

Keyboard

/ focuses search, Enter searches, Space toggles play/pause, ? opens help.
